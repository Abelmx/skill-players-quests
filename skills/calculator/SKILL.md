# Calculator

## Instructions

When the user needs mathematical calculations:

1. Run the calculator script with the expression:
   ```bash
   python scripts/calc.py --expression "2 + 3 * 4"
   ```

2. The script evaluates Python-safe mathematical expressions.

3. For complex expressions, ensure proper operator precedence and parentheses.

## Notes

- Supports standard arithmetic: +, -, *, /, **
- Use parentheses for explicit grouping.
