# Frontend Design

Create distinctive, production-grade frontend interfaces following specific design system rules.

## Before writing

**Before writing any code, read references/design-system.md for required design constraints.**

## Design thinking process

1. **Understand constraints** – Read the design system to avoid forbidden patterns and meet required rules.
2. **Choose typography** – Select a distinctive Google Font (e.g. Space Mono, Playfair Display, DM Serif Display, Instrument Serif, Syne, Unbounded).
3. **Define palette** – Use CSS custom properties for colors.
4. **Plan layout** – Use asymmetric, grid-breaking, or overlap layouts instead of centered cards.
5. **Add motion** – Include CSS animations or transitions.
6. **Ensure accessibility** – Follow WCAG 2.1 AA (labels, contrast, focus styles).
